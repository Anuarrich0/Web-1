О проекте: как создан этот сайт

Здесь мы рассказываем, какими технологиями, инструментами и принципами руководствовалась команда при разработке сайта Underground Gym, а также отвечаем на часто задаваемые вопросы о проекте.

Технологии

Сайт создаётся поэтапно, в рамках учебных заданий, с постепенным наращиванием функциональности.

HTML5
Семантическая вёрстка каждой страницы: осмысленные теги (header, nav, main, section, article, footer) вместо универсальных div, где это возможно.
CSS3
Стилизация и адаптивная вёрстка — запланированы на следующий этап работы.
JavaScript (ES6+)
Интерактивная логика — калькуляторы стоимости, квизы, фильтры филиалов и переключатель темы — запланирована на следующее задание. В разметке уже подготовлены соответствующие атрибуты и id-«крючки» для будущих скриптов.

Структура проекта

Сайт состоит из восьми связанных между собой шаблонов страниц:

  • index.html — Главная: баннер, статистика по 11 филиалам, акции и партнёрские скидки.
  • pages/locations.html — Филиалы и карта: сравнительная таблица залов.
  • pages/services.html — Услуги и зоны: силовая, функциональная и групповая зоны.
  • pages/training.html — Тренировки: форма подписки на рассылку.
  • pages/pricing.html — Абонементы и цены.
  • pages/promotions.html — Акции и партнёры.
  • pages/colophon.html — О проекте и FAQ (эта страница).
  • pages/contacts.html — Контакты.

Общие для всего сайта изображения хранятся в каталоге assets/images/ и переиспользуются на всех страницах через относительные пути.

Инструменты и процесс разработки

  • Редактор кода: Visual Studio Code с расширением Live Server для предпросмотра страниц в браузере без сборки проекта.
  • Контроль версий: Git и GitHub — каждое задание фиксируется отдельными коммитами, история изменений доступна в репозитории проекта.
  • Проверка вёрстки: инструменты разработчика браузера и ручная проверка семантики и доступности (атрибуты aria-*, альтернативный текст изображений).

Команда проекта

Сайт разрабатывается совместно небольшой командой в рамках учебного курса: каждая страница закреплена за отдельным участником, а общий шаблон шапки и подвала используется на всех страницах для единообразия.

Главная страница и общая структура разметки подготовлены А. Максатом; остальные разделы дорабатываются другими участниками команды.

Часто задаваемые вопросы

Почему на сайте пока нет стилей и анимаций?

Проект выполняется поэтапно: сначала прорабатывается семантическая HTML-структура, затем добавляются стили (CSS3), а после — интерактивность (JavaScript). Сейчас сайт находится на первом этапе.

Будет ли сайт адаптивным для мобильных устройств?

Да, адаптивная вёрстка запланирована вместе с добавлением CSS3. Кнопка мобильного меню уже подготовлена в разметке шапки сайта.

Когда заработают калькулятор абонемента и фильтр филиалов?

Эта функциональность появится на этапе подключения JavaScript (ES6+). В разметке уже есть необходимые id и data-атрибуты, которые будут использоваться скриптами.

Это реальный фитнес-клуб или учебный проект?

Underground Gym — учебный проект для отработки навыков семантической вёрстки HTML5. Указанные контакты, адреса и отзывы используются в демонстрационных целях.

Как связаться с командой проекта?

Свяжитесь с нами через страницу контактов или по телефону, указанному в шапке сайта.
